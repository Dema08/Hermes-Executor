# Hermes-Executor

Roblox Executor dengan Desain Premium Dark Theme & Aksen Emas (Terinspirasi dari Dewa Hermes - Cepat & Elegan).

## Spesifikasi Teknis
- **Framework**: .NET 9.0 (WPF)
- **Editor**: AvalonEdit dengan Lua Syntax Highlighting
- **UI Libraries**: ModernWPF, FontAwesome.Sharp

## Struktur Proyek
- `Core/Injector.cs` - Logic deteksi & inject Roblox
- `Core/ScriptEngine.cs` - Logic eksekusi script
- `Views/` - Komponen & Halaman Pendukung
- `Styles/` - Tema Gelap & Hermes Gold Theme
